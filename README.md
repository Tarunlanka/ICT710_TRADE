## Project overview
CLEAR TRADE is a user-centred redesign concept for a mobile trading application. The redesign focuses on fund transfers, automated-trading setup, transaction confirmation, Buy/Sell navigation, and contextual help.

## Design responses
- Replace ambiguous In/Out labels with **Add Money** and **Withdraw**.
- Name both accounts and restate transfer direction at review and confirmation.
- Use a five-step automated-trading wizard with a plain-language rule summary.
- Show transaction costs before commitment and require explicit confirmation.
- Keep Buy/Sell controls in a consistent location.
- Provide contextual help within high-friction flows.
