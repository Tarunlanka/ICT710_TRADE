# CLEAR TRADE — Mobile Trading App UX Redesign

**Course:** ICT710 Interaction Design and Usability | **Assessment:** Assessment 3 Part A  
**Institution:** Victorian Institute of Technology

## Overview
CLEAR TRADE is a user-centred redesign concept for a mobile trading application, focusing on fund transfers, automated trading, transaction confirmation, Buy/Sell navigation, and contextual help.

## Baseline reported in the assessment
The basis report uses simulated data from five participants, so results are indicative and not statistically significant.

## Design responses
- Use **Add Money** and **Withdraw** rather than ambiguous In/Out labels.
- Name both accounts and repeat transfer direction in review and confirmation.
- Use a five-step automated-trading wizard with a plain-language rule summary.
- Display costs before commitment and use explicit confirmation.
- Keep Buy/Sell controls in a consistent location.
- Provide task-aware help within high-friction flows.

## Evaluation status
The report describes completed expert inspections: cognitive walkthroughs, heuristic inspection, and accessibility checks. A participant re-test is planned but **has not been conducted**. Expert findings are predictions, not proof of improved real-user performance.
