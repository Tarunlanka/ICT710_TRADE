# AI-Assisted Design Evidence

## Purpose
Document where AI-assisted brainstorming or drafting supported the design process. This file is not a substitute for the assessment's required original prompts, outputs, screenshots, or declarations.

## Design questions explored
- How could fund-transfer direction be made more explicit?
- How could automated-trading setup be broken into understandable steps?
- What details should users review before submitting an order?
- Where might contextual help reduce errors?

## Design decisions retained
- Explicit Add Money and Withdraw labels.
- Named source and destination accounts, with direction repeated during review.
- A five-step automated-trading wizard and plain-language summary.
- Visible transaction costs and explicit final confirmation.
- Consistent Buy/Sell placement and task-aware help.
