# Accessibility Check

## Checklist for review
- Confirm text contrast against the applicable WCAG success criteria using measured colour values.
- Do not use colour alone to communicate Buy/Sell status, errors, or success.
- Ensure interactive targets are large enough and sufficiently spaced for touch.
- Provide visible labels and instructions for all input fields.
- Ensure errors are described in text and associated with the relevant field.
- Check reading order, focus order, and keyboard/screen-reader access in the implemented prototype.
- Use clear, descriptive labels for buttons and controls.
- Verify that text can be resized without loss of content or functionality.

## Status
This checklist is not a formal accessibility conformance statement. Record the tool, test conditions, measured values, and outcomes before claiming that a criterion passes. Verify any citations in the final report against the actual sources used.
