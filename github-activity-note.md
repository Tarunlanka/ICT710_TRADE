# GitHub Activity and Evidence Note

This repository was assembled as project documentation. The current commit history reflects when files were actually uploaded; it should not be represented as a historical record of earlier group work.

## Evidence to collect genuinely
- Screenshots of real group discussions with dates visible.
- Links to actual documents, prototypes, and version history.
- Genuine GitHub commits and pull requests created by the people who performed the work.
- Meeting notes that were actually taken.
- Confirmation of each member's contribution.

Do not create fake historical conversations, backdate commits, or attribute commits to another person. If evidence was not recorded at the time, explain that honestly rather than reconstructing it as if it were original.
